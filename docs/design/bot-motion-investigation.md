## Observed reference evidence

The browser title was Cloudflare's verification page; its empty SVG/canvas inventory describes the challenge, not the application. The web reader returned public page text only. The user-supplied empty SVG wrapper does not identify the rendering technique. The official character geometry, blink algorithm and pointer behavior remain unobserved.

Generic pointermove/requestAnimationFrame strings in React infrastructure are not evidence of author-specific behavior. Independent read-only review confirmed these claim boundaries.

## REA setup and scope

The npm registry identifies rea-agents 6.5.0, its official morluto/rea repository and versioned tarball. The package, entrypoint, prepare script, setup implementation and bundled instructions were inspected before use. Acquisition used ignore-scripts. No analysis engine was installed.

The Codex setup dry-run proposed modifying the user's global .codex/config.toml. A CLI-only dry-run listed no actions. Automatic approval review nevertheless rejected setup --yes because it could create persistent MCP access. It was not retried or bypassed. CLI list-browser-targets, inspect-web-page and analyze-web-bundle worked without MCP registration. Setup is not represented as completed, nor are new MCP tools claimed to be connected.

## Implementation boundary

The replacement is original native SVG/CSS, authored for the workshop rather than copied from reference paths, proprietary bundles or screenshots. It uses one black character, bounded body motion, a smaller face-gaze offset, and native ellipse scaling for eye closure. The supplied PNGs and black eyelid masks are removed from the application. Feedback and results use the approved pre-mascot shell. Reference scripts and third-party screenshots are not shipped in the product or evidence folder.
